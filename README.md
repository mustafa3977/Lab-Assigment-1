This project implements a user registration system using a clean separation
of concerns in Node.js (OOP-based backend) and a simple, attractive
HTML/CSS frontend.
It allows users to input their name, email, and password, which is securely
hashed using bcrypt.
The system checks for duplicate emails before saving a new user in an inmemory database.
The backend uses Express.js with modular controllers, services, and routes.
Frontend submits data using fetch API to a /register endpoint.
The code structure follows best practices for maintainability and scalability
